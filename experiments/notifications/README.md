## 运行

使用 Windows PowerShell 5.1 编译 Build-Experiment.ps1，指定一个新的 Destination EXE。运行 EXE 的4个参数依次为 Start-Experiment.ps1绝对路径、现有instances.local.json绝对路径、新的输出目录、运行秒数（30至900）。实验窗口可以直接点“停止实验”，到期自动退出。

点击“模拟官方端完成”或“模拟 API 端完成”，将只向隔离日志追加模拟task_complete事件；读取器解析后显示对应提示。卡片“打开”按钮只找回已运行环境，不启动停止的环境。窗口多义时拒绝猜测。

只读监听选项仅取启用时当天最近的最多16个日志文件/环境，不自动发现后续新文件，不跨天，不持久化游标。这些是实验边界，正式集成前须补齐。已有历史事件不重放；仅接收Codex Desktop/vscode主任务，跳过子代理。读取器22项隔离测试通过。

系统托盘气泡方案在先前实验收到notification-shown事件，但无实际点击证据，不把它视为通过；默认改为可见卡片。
