# 原生重命名接入

原创实现，不复制 Codex++ 代码。仅给绑定的 API 实例的原生“重命名聊天”弹窗增加建议区，不自动保存，不写 SQLite 标题。

## 当前交付

这是独立实验组件，不包含在标准控制器完整包或升级包内。2026-10-16 交接记录中的版本为 `native-title-0.1.5-20261016`，已更新本机下一次启动配置；交接核验时，当前窗口仍由 0.1.4 加载器服务。该记录不代表当前运行状态，也不代表通用安装包已经交付。

0.1.5 新增经严格验证的 Desktop → BridgeProxy → CLI 识别，并在升级标题集成区时保留其他启动器片段。MSIX 激活、DPAPI、Home/Profile 与供应商配置保留。用户已确认此前 0.1.4 能生成并采用标题；**0.1.5 与新自适配桥接同时运行的日常体验仍待完整重启后人工验收**，不能将旧版本反馈视为新组合通过。

需要 Windows PowerShell 5.1、Node.js、Python、Codex Desktop/CLI 和控制器依赖。安装器仍含本机路径默认值及特定启动器模板约束，准备阶段仍要求运行中的直接 CLI；维护者须先审查实际路径、依赖与启动器结构，不能直接作为面向所有用户的一键安装。不要为安装测试结束正在承载任务的 Desktop。

日常入口下一次完整启动时：

1. 校验 bundle、Controller 依赖和 Desktop/CLI/Node/Python 哈希，确认唯一 API 实例及其目录；运行时仅接受已核验的直接 CLI 或 Desktop → BridgeProxy → CLI 链。
2. 传 `--remote-debugging-port=0`，核验 Profile 中新建的 DevToolsActivePort、实际回环监听 PID 与 browser path。
3. 隐藏运行加载器，只接纳指定客户端的 `app://-/index.html` 主页面，排除浏览器、远程网页、小窗和 avatar 页面。
4. 加入原生弹窗建议控件。侧栏右键、菜单或双击提供明确聊天身份；不能确认身份就保留手动重命名，不猜测目标。
5. 只传聊天 ID，由固定 API Home 的只读索引获取该聊天上下文。尾部读取最多 2 MiB，从中选最多五轮/十条纯文字、总量最多 8000 字符；长工具记录挤出用户消息时，回退到该聊天最初问题的前 2000 字符。不会扫描整段历史或发送工具/图片内容。
6. 独立无工具临时 CLI 用 `gpt-6-luna`、low 推理生成标题，沿用当前供应商；打开弹窗或“再想一个”才会调用模型，无后台模型轮询。

使用方式：等 API 客户端启动完成，右键侧栏某条本地聊天，选择“重命名”。出现“标题建议”后可采用、继续编辑，再点原生“保存”。开始手动输入、关闭弹窗、切换聊天后，迟到结果作废。

## 可靠性与回退

模型工具能力探针在 PrepareOnly 时运行，不在每次启动 Worker 时再运行；结果与 CLI 哈希绑定。这样启动关闭不会把尚在探测的 CLI 留下。接口错误、超时、目录变化均保留原生手动输入。每页面最多三次加载尝试并退避，版本不兼容不会无限注入。

安装目录的“检查标题增强.cmd”输出脱敏运行状态。“回退标题增强.cmd”停用组件并精确撤回本次启动补丁，保留启动器其他位置的后续修改。完整退出 API 客户端后调试端口才彻底关闭。若官方客户端或控制器升级改变依赖哈希，增强会停止该次加载并保留原生启动，需重新适配，不能简单改哈希绕过验证。

## 源码入口

`renderer.js` 为前端，`loader.mjs` 为受限 CDP/stdio 桥接，`worker.py` 为可取消请求处理；父目录 `native_context.py`、`title_service.py` 为摘要与生成服务。四份 PowerShell 文件负责准备、安装、实例验证、生命周期与字段级回退。

当前只支持本机 Windows API 实例；不把远程 host、云聊天、另一个官方 Home 或任意网页纳入自动建议。
