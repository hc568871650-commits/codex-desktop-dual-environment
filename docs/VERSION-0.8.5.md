# 0.8.5 本机缺陷修复

2026-10-03。本机安装版，不代表公开发布。

- 完成提醒在已核验的 API 主窗口处于前台时静默，仅保留最近记录；切到后台不补发旧事件。判断同时核对程序路径、CODEX_HOME 和 Desktop profile，原版窗口不会误抑制 API 提醒。显式预览和待作答问题不受此规则影响。
- 提问代理处理控制器管道断开时，覆盖读取、写入和释放 StreamWriter 的异常边界，避免一次清理异常结束代理及其 app-server。
- 未知异步问题结构继续原生透传，不因空问题或非对象条目终止输出线程。
- 支持同一 API Desktop 同时启动多个 app-server：各连接使用独立管道，控制器汇总待处理问题，并按连接身份回传答案。旧进程的过期注册不会错误接收回答。

新代理采用独立版本目录和绑定。升级控制器不强制退出正在承载任务的 API Desktop；已经运行的旧代理需要在本次任务结束后完整退出并重新启动 API 版才能替换。实际验证结果和回退路径见本机安装记录。
