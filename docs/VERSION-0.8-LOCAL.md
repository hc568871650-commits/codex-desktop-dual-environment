# 0.8.0 本机更新

本文件记录 0.8.0 本机迭代当时的状态；0.8.0–0.8.2 未单独公开。后续 0.8.3 的当前行为与发布边界见 [VERSION-0.8.3.md](VERSION-0.8.3.md)。

- 通知显示设置：预设/自定义时长、常驻、淡入淡出。此处“悬停暂停”为 0.8.0 当时行为；从 0.8.2 起普通提示悬停或获得焦点不暂停计时。
- 提问窗口默认为 480×380 的角落小窗，跟随深浅主题，可滚动作答；保留较大调试预览。
- 通知页增加待处理列表和提问预览；正式问答管道的 API 环境绑定、失效检查及回退处理已接入控制器源码。
- 从通知返回任务不再因链接不支持或后台错误自动显示控制面板，改为角落反馈。

安装此控制器更新不会自动启用 API stdio 桥接、关闭原生通知或修改 Codex 启动器。真实桌面问答与全部通知类别仍按隔离验证流程推进；日常环境没有绑定桥接时，可使用提问预览，真实提问仍在 Codex 内处理。

升级使用现有带哈希校验的备份/回滚机制，保留实例配置、偏好和 Codex 数据。部署记录与此次专用回退入口由本地维护目录单独保存。
