# 0.8.7 通知界面精简

2026-10-03，本机更新。

- 完成提醒和待回答提醒采用统一卡片：短状态、可换行正文、右上角 ×。点击正文或空白主体打开任务/问题，× 只关闭提示。
- 移除“查看任务”“关闭提示”“暂停提醒”“查看并回答”“稍后处理”以及重复说明。短内容卡片自动收紧，长内容增高到受限高度并换行。
- 提示卡片同一时刻只显示一张；替换或关闭卡片不删除完成历史，也不取消待回答问题。
- 返回任务反馈使用同一布局，移除“知道了”按钮，保留错误原因和关闭操作。
- 通知开关、暂停和恢复集中到控制台通知页；托盘通知入口只负责进入设置，快捷通知页仅保留设置、待处理问题、最近完成三个入口。
- 独立作答窗移除重复标题及常驻说明；保留任务标题、实际题目、选项、自由输入、返回 Codex、提交。正常状态省去说明行，提交或异常时才显示状态。
- 0.8.6 的前台原生提问、后台独立提问及完成提醒抑制保持原行为。沿用当前代理，只需更新控制器，不重启 API 客户端。

共用的卡片组件集中处理排版与点击区域，后续通知样式调整可以在同一入口完成。
