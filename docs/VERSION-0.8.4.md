# 0.8.4 本机安装版

2026-10-03。本机安装，不代表公开发布。

- 自动完成提醒和历史只接受已登记 API 实例；原版仍可手动管理。
- 控制台和作答窗分别支持聚焦/不抢焦点与普通层级/置顶。
- 提问服务支持同步、异步问题接管、回答确认、原生回退和未知提交防重复。
- 新增明确的本机生产绑定，与隔离实验绑定分别校验；包括 API home/profile、实例 ID、用户 SID、配置和三类程序哈希。
- API 启动器在校验通过时选择提问代理，DISABLED、缺文件或软件更新不匹配时沿用原生 CLI。原版启动器不修改。

本机默认问题小窗不抢焦点并置顶；控制台打开时聚焦、不置顶。既有主题、窗口位置、通知时长、环境登记和模型配置保留。

安装可以在两套 Codex 继续运行时完成；已经运行的 API Desktop 不会被动态注入代理，需下次完整退出并重新启动 API 版生效。控制器重启不等于 API 接管已生效。

桥接目录与控制器部署快照由本机部署记录管理。停用接管、原生启动和总回退分别有独立入口；总回退恢复控制器程序、API 启动器及问题绑定，保留其他个人偏好的后续变更。

先前实验的验证范围见 `CHECKPOINT-QUESTION-TAKEOVER-20261003.md` 和 `ASYNC-TAKEOVER-PROTOCOL-20261003.md`。审批及未知新问题结构继续原生处理，完整 Desktop 多窗口、所有通知与历史恢复路径不作为已经全面验收的结论。
