# 0.8.6 前台原生提问修复

2026-10-03，本机修复版。

- 已核验的 API 主窗口在前台时，控制器不接管新提问，同步及异步问题使用 Codex 原生界面。
- 后台已接管的问题在用户返回 API 窗口后恢复原生入口，确认交回后收起独立小窗；草稿保留且不重复发送。
- 切到后台后，新问题仍按用户设置显示独立小窗或提醒。已经交给原生的问题不会被再次夺回。
- 异步快照返回期间发生前台切换时，显示入口再次核验前台，避免短暂闪出独立窗口。
- 结果未确认的在途答案仍禁止重复提交，不为了切换界面而放出第二个回答入口。

沿用已安装的 0.8.5 多连接代理及其绑定。本次只重启控制器，不重启 API Desktop、代理或 CLI。
