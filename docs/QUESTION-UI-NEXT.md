# 提问界面与控制器接入（0.8.3 界面已安装）

0.8.3 的作答窗与控制器界面已在本机安装；日常 API Desktop 的提问桥接仍未启用，真实问题继续由 Codex 原窗口处理，也未接管全部原生通知。以下隔离测试结果不代表真实 Desktop 问答已验收。

## 使用路径

- 控制器“通知”页分为“待处理”和“最近完成”。有新问题时切到待处理，并显示不抢输入焦点的提示卡片。
- 点击卡片“查看并回答”或待处理行打开正式作答窗。默认 480×380，位于通知所在屏幕工作区右下角，保留 20px 边距并避开任务栏；不单独占用任务栏。窗口支持长问题、多题滚动、选项说明、其他答案、自由输入和敏感输入隐藏。
- 只有完整填写并主动提交才会发送答案。关闭作答窗保留同一问题的草稿；提示卡片收起不会回答、取消或丢弃问题。
- 提示卡片沿用显示设置中的时长、常驻和动画；作答窗口不自动关闭，避免中断输入。
- 问题在原入口解决、任务结束、连接中断或桥接回退后禁用提交。失败不会自动重发答案。
- 作答窗跟随控制器深浅主题和强调色。可读到任务标题时显示标题；否则使用“API 任务”标签。
- 托盘菜单增加“待处理问题”入口。

“连接提问”只接受已经验证的隔离桥接目录，必须与当前控制器登记的 API home/profile 完全对应，且程序哈希匹配。不能把日常控制器随意连接到另一个测试环境。绑定记录在控制器自己的 `state/question-bridge.local.json`，问题及答案不落入该文件。

## 预览

开发源码根目录双击 `Preview-Questions.cmd`，或执行：

```powershell
powershell -NoProfile -STA -ExecutionPolicy Bypass -File scripts\Preview-Questions.ps1 -Theme light
```

控制器中也可进入“通知 → 待处理 → 预览提问”。预览明确标注身份，提交和返回按钮都不会操作真实任务。源码根目录 CMD 是开发便利入口；安装包中的预览可通过控制器按钮或 scripts 中的脚本使用。

原来的较大视图保留为可选调试预览：源码根目录运行 `Preview-Questions-Expanded.cmd`，或给预览脚本加 `-Expanded`。日常默认是角落的小窗口。

从通知、最近完成或作答窗返回任务时，不自动显示控制面板。任务链接不支持、目标打开失败或后台工作异常时，保留独立的角落提示；已由用户主动打开的面板不会被强制关闭。普通控制面板操作原有的错误反馈保持不变。
