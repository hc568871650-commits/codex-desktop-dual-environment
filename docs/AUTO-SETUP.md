# 0.3.1 自动安装与升级

把新包解压到新文件夹，双击 `Start.cmd` 或 `Install.cmd` 即可。两者执行同一流程：

| 检查结果 | 自动操作 |
|---|---|
| 没有已有安装 | 进入首次安装，询问官方目录和 API 配置 |
| 找到一套旧安装 | 备份并更新原目录的工具，复用原配置 |
| 同版但缺少工具文件或控制面板桌面入口 | 修复工具并补建控制面板入口 |
| 版本、工具文件和控制面板入口均完整 | 直接打开已有控制面板 |
| 找到多个候选目录 | 显示候选路径，要求选择目标 |
| 清单无法解析、目录错位、入口冲突或安装包版本较旧 | 停止并说明原因，保留现有文件 |

控制器正在运行时，升级会提示先退出控制器，再点击“重试”；两个 Codex 窗口可以继续运行。不会为了更新而强制结束用户进程。首次安装的登录自启动仍默认关闭，已有用户的选择保留。

识别范围包括当前解压目录中的安装配置、默认安装位置、此前统一入口保存的安装位置、运行中的控制器、当前用户的控制器启动项，以及桌面快捷方式目标。多个线索指向同一规范路径会合并。只凭某个目录存在或名称类似，不会允许覆盖；还要核对安装清单、产品版本与实例配置。

程序不会扫描所有磁盘。早期自定义安装如果没有快捷方式、没有启动项且未运行，可能无法发现；这种情况可明确指定工具目录：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File scripts\Bootstrap.ps1 `
  -TargetDirectory 'D:\CodexDual\Tool'
```

`-TargetDirectory` 优先于自动发现；目标为空时安装，已有有效配置时升级。旧版 0.1 的自定义设置可附加 `-LegacySettingsPath`。`-CheckOnly` 只返回计划，不创建目录、更新文件或启动程序；`-NoLaunch` 完成后不打开面板；`-NonInteractive` 在缺少首次安装参数或需要人工选择、退出控制器时直接报错，便于自动部署。`-SearchDirectories` 可限定候选目录范围。

使用 `-ShortcutDirectory` 可改变新快捷方式的位置；受旧 WScript 接口限制，英文 Windows 等环境应选择完整 ASCII 路径。`-NoShortcuts` 可跳过快捷方式创建/修复。升级只自动补建 `Codex Dual Controller.lnk` 控制面板入口；首次安装还会创建官方和 API 的独立快捷方式。已有同名不同目标或带其他启动参数的入口不会被覆盖。

升级和补建入口属于同一回滚流程。更新失败会尝试恢复旧工具并移除本次新建入口，原始异常和失败阶段会保留。回滚前检查文件哈希，保留用户后续修改。为了能够恢复旧工具文件，推荐解压到新目录后运行统一入口，而不是先手动覆盖旧目录。
