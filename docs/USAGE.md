# 操作、配置和故障排查

## 入口

- `Install.cmd`：新部署，交互询问官方 home 与 API 配置。
- `Start.cmd`：存在默认/同目录安装配置时打开控制器，否则进入安装。
- `Controller.cmd -ConfigPath "绝对路径\instances.local.json"`：使用指定配置。
- `Controller.cmd -ConfigPath "绝对路径\instances.local.json" -Action official`（或 api）：与托盘复用同一定位逻辑。
- `powershell.exe -NoProfile -File src\Controller.ps1 -ConfigPath "..." -Action status`：只读状态。
- `Configure.cmd`：旧版 API 配置界面，仅保留配置和诊断；不作为实例启动入口。
- `Uninstall.cmd`：仅移除清单内未修改的工具文件和快捷方式。

每次重新加载控制配置请退出再启动控制器。退出控制器不会关闭 Codex；菜单状态在每次打开时刷新，不持续扫描任务。

## 配置

模板位于 `config/instances.example.json`。`id` 是安装/注册时随机生成并持久保存的 UUID（32 位十六进制）；无需因 PID 变化修改它。运行记录不作为唯一身份依据。

`home`、`profile`、`projects`、`projectless` 必须是独立本地绝对目录，不能彼此嵌套或使用目录联接。官方 profile 为空表示沿用默认 profile，API 必须显式设置。官方默认 profile 的物理位置由 Codex 控制；工具不声称配置了官方 profile 的新目录。

`executable` 留空每次查 Store；也可指定安装目录或桌面 EXE。用户需确认手动路径来自可信安装，不选择 CLI。更新时优先使用新查询到的程序；仍运行的旧路径仅在原身份记录与进程吻合时允许定位，否则显示未知，要求明确确认路径。

`launchMode`：official（直接启动）、managed-api（本工具 DPAPI 凭据）、external（现有 PowerShell 启动器）。托管 API 的各目录必须与 apiRoot 一致。external 模式不加载/迁移密钥，不保证外部脚本无副作用。

项目目录是启动工作目录，不限制用户之后选择其他项目。无项目任务目录启动前与 config.toml 比较；不支持任意复杂 TOML 写法，解析不确定就停止，不猜测。

## 常见问题

**显示状态未知。** 可能是访问级别不同、非 x64 进程、读取 PEB 失败、profile 冲突、多个主进程或旧 EXE 路径未登记。确认路径和权限；不要用管理员权限随意接管另一个账户，也不要修改 PID 绕过检查。

**窗口恢复但没有到最前面。** Windows 拒绝后台抢焦点时控制器明确提示。使用托盘菜单再次点击或点击对应已恢复窗口的任务栏按钮。不发全局快捷键、不降低安全设置。

**有进程但无窗口。** 主窗口可能已销毁或尚未创建。当前版本不会再次启动一个进程来赌 Electron 转发；从原生托盘恢复，或确认无任务后单独退出再启动。

**退出后仍有后台进程。** WM_CLOSE 可能仅隐藏到托盘。控制器等待后询问强制退出，默认否；强制结束前再次核验。独立 app-server、终端及外部应用仅列出保留，不按名称杀掉。残留报告针对退出前观察到的进程树，不保证发现已经重新挂到其他父进程的外部应用。

**提示正在处理另一个操作。** 同一环境的另一个启动/退出操作持有互斥锁，稍后重试。不是新建第二个实例。

**安装已有配置但缺少 projectlessWorkspaceRoot。** 工具不改写现有官方 TOML；自行在 `[desktop]` 下设置独立路径，再安装。单/双引号字面字符串可解析，复杂转义、内联注释或动态拼接可能拒绝。

**卸载后的快捷方式失效。** 移动到收纳应用的快捷方式不被扫描删除，手动移除即可。用户数据保留。要恢复使用，在完整工具目录传入保留配置路径；不要覆盖旧数据。

## 实现与权限

系统 WinForms、CIM、Win32 与 DPAPI，无额外运行时。PEB 环境读取是只读、仅返回 CODEX_HOME；其他环境变量不输出或保存。它是版本敏感实现细节，不是安全边界。身份不可读时不降级到仅按进程名识别。

新启动进程清理继承的 Codex/OpenAI 会话变量，使用独立环境块。标准输出/错误连接 NUL，避免桌面日志进入控制器终端或父进程退出导致日志管道断裂。不会保存 API 内容日志。

安装清单记录新增工具文件、快捷方式及哈希，卸载只删未修改的清单文件，配置与数据全部保留。安装和卸载无全局环境变量、计划任务、自启动或协议注册修改。

## 固定任务栏

安装后运行 CodexDualController.exe，右键该文件或其任务栏图标选择“固定到任务栏”。点击固定项打开小面板；关闭面板收起到托盘；重复点击找回同一面板。两个“打开”按钮绑定配置中的日常实例，退出按钮仍单独确认。退出控制器不退出 Codex。没有开机自启。

已有环境可使用 `scripts/Deploy-Controller.ps1 -ConfigPath <已验证配置> -Destination <空的固定目录>` 部署，仅复制工具与无密钥的控制配置，凭据仍由原启动器负责。部署目录不可移动；卸载后手动取消任务栏固定。
