# 可选迁移：默认不执行

默认安装保留现有官方 home 和默认 profile，不迁移登录、认证或聊天数据。首版没有自动迁移按钮；迁移与安装分别进行。

如确实需要换盘：先在两边确认没有任务，再用各自正常退出入口退出并检查残留。备份原数据后，使用自己选择的文件工具复制需要迁移的数据，校验数量/哈希；原副本保留直到重启验证通过。不要在数据库写入期间直接剪切目录。

认证文件不由本工具复制。迁移后需要登录时在官方界面重新登录。修改控制器配置中的 home、profile、projects、projectless，并检查 Codex 配置中的 projectlessWorkspaceRoot 与之相符。修改后重启控制器，旧实例若仍运行会因归属冲突被拒绝操作。

旧任务可能保存绝对路径，单纯复制不保证旧任务链接可用。第一版拒绝联接/符号链接的数据路径，不提供自动路径重写或迁移回滚；需要这些能力时应另行设计和验收。遇到问题切回仍保留的原路径，不覆盖原始数据。
