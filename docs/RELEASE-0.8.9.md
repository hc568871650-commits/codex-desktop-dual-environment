# v0.8.9 · 退出交互、组件诊断与问答草稿保护

相对公开版 v0.8.8，本次更新标准控制器：

- 退出实例改为一次明确确认后直接结束已核验目标，取消保留；继续保护当前宿主及不能确认归属的外部进程，结果在面板内反馈。
- 修复重复打开控制器时，提前返回后的清理错误。
- 增加通知、提问桥接、守护后台/CLI/托盘和自适配六项只读诊断，不启动组件、不调用模型。
- 桥接校验提供明确原因码；安全刷新登记，待答、提交、排队结果、所有权移交、隐藏草稿或旧代理仍存在时不切换。
- 连接失效与确认处理分别标记，隐藏窗口保留未解决草稿。

## 下载与升级

首次使用下载 `CodexDualLauncher-0.8.9-windows.zip`；已有安装下载 `CodexDualLauncher-0.x-to-0.8.9-upgrade.zip`。解压到新目录后运行 Start.cmd，升级前退出控制器，正在工作的 Codex 可保持运行。升级保留配置、凭据和用户数据，备份可通过 Rollback.cmd 恢复。SHA-256 见附件清单。

## 实验范围

标准安装包及升级包排除整个 experiments 目录。源码仓库保留自适配提问代理、原生标题建议 0.1.5 和守护桥接兼容实验；不提供通用一键安装，仍有本机路径默认值、启动器模板和依赖约束。

自适配使用本地 Responses fixture 检查已覆盖协议，不调用供应商模型；标题生成会调用用户配置的供应商 API。此前标题 0.1.4 的生成与采用有用户反馈，但 0.1.5 与自适配桥接的真实 Desktop 重启后组合体验尚未验收。标准包安装不意味着获得自动标题或自动适配。

## 验证

本地完整回归 32 套通过；发布准备包通过真实 v0.8.8 升级、新装和回滚的 20 项检查。问题窗口 25 项、接管与返回原生 32 项通过。自适配核心 30、启动集成 15、标题启动/升级/回退 53 项通过。隔离测试不等于所有 Desktop 版本及日常窗口组合验收。
