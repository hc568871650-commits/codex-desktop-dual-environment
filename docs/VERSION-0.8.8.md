# 0.8.8 回答后统一收起

2026-10-03 完成本机更新；v0.8.8 同时作为 v0.8.3 之后的累计公开版本，包含未单独发布的 0.8.4–0.8.7 更新。公开交付范围、回归与附件见[发布说明](RELEASE-0.8.8.md)。下面保留本机修复和专项验证记录。

- 独立作答窗收到回答成功回执时，在同一次界面更新内隐藏窗口并关闭对应问题通知，不再停留在“回答已发送”状态，也不等待通知显示时长。
- 问题在原生入口处理，或先前未知结果随后确认时，在下一次有效状态同步中自动收起。状态轮询间隔仍为 900 毫秒；不承诺连接异常时的关闭时限。
- 传统问题的成功回执表示答案已写入本地 CLI；异步问题须收到对应轮次的成功确认。等待期间保留提交中状态，禁止重复提交。
- 超时、连接不可确认时保留作答窗和草稿。多连接状态附带实际响应的连接标识，其他连接的空列表不能证明当前问题已经处理。
- 关闭逻辑按请求标识匹配，延迟返回的旧回答或返回原任务回执不会误关正在编辑的新问题。
- 界面预览仍保留“答案未发送”反馈；它没有真实提交回执，不参与自动收起。

验证：控制器问题集成 25 项、异步接管与前后台切换 32 项、多连接 30 项、问题窗口 29 项，共 116 项通过。本次更新只替换控制器，沿用现有代理，不重启 API 客户端。
