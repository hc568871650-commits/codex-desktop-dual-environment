# 0.9.0-preview.4 · C# 控制器公开预览

本次将常驻控制器迁移到 C# / .NET 10，完成通知监测合入后台任务，并整理界面。发布类型为 **prerelease**；稳定版仍为 0.8.9。

## 更新内容

- 主程序不再加载 PowerShell Runspace；安装、维护及部分外部启动器仍使用 PowerShell。
- 通知采用有界读取、文件变化监听和低频补扫，保留去重与续读，大附件行不会阻断后续完成事件。
- 标题适配动态发现官方 CLI，先做离线兼容检查，再允许标题生成；原生保存保留用户采用和编辑步骤。
- 主导航整理为工作台、通知、连接、设置；修复页头按钮遮挡、下拉菜单关闭后访问已释放对象，以及临时目录清理错误掩盖标题结果。
- preview.4 补齐统一版本、自包含 Windows x64 包、首次安装、升级所有权清单、回退、卸载与 C# CI。首次安装默认关闭实验标题挂接，已有设置保留。
- 修复英文 Windows 下中文路径快捷方式创建失败，以及小窗口下页头操作超出可点击区域的问题。

## 下载与安装

附件 `CodexDualController-0.9.0-preview.4-win-x64.zip` 同时用于首次安装和升级，包含 .NET 10 Desktop 运行时；`SHA256SUMS.txt` 提供 SHA-256 摘要。需要 Windows x64、Windows PowerShell 5.1 和 Codex Desktop。

将 ZIP 解压到独立目录。新用户运行 `Install.cmd`；已有用户退出控制器后运行 `Upgrade.cmd` 并选择原工具实际目录。不要直接把新文件覆盖到旧安装；升级生成独立回退备份并保留用户配置和数据。详细步骤见包内 README 或 [安装与回退说明](DOTNET-INSTALL.md)。

## 验证与已知边界

C# 核心、隔离 WinForms 交互、包清单、首次安装、旧版升级、配置与凭据保留、回退和卸载由本版本 CI 检查。旧 PowerShell 回归单独保留，不替代 C# 检查。构建仍有旧控件及兼容代码的 nullable 警告。

本地候选已有 22 项 C# 核心检查、20 个标题前端隔离场景、22 项安装包检查及 32 套旧控制器回归通过记录；最终包检查增加最小窗口尺寸回归，共 25 项。安装包检查从 ZIP 解压后执行，以公开 0.8.9 附件为升级基线，覆盖中文和空格路径、深浅两套主题、每次 30 次菜单选择与页头命中，以及逐文件回退。测试没有调用真实模型或启动完整 Codex Desktop。最终提交的 CI 状态和公开附件校验以 Release 页面记录为准。

标题建议与提问桥接属于实验能力。外部启动器需按说明单独接入；公共安装不修改它，也不安装提问代理。原生标题弹窗完整交互、自然任务提醒、跨窗口与前后台所有组合、长期内存稳定性尚未全面验收。分项合成测试不等于真实日常模型流程。性能历史记录仅供对照，不承诺固定内存或整体提速倍数。
