# 通知显示设置（0.8.3 已安装，桥接未启用）

0.8.3 已在本机控制器的“通知”页提供“显示设置”入口，作用于控制器的完成通知卡片和通知预览。发布状态以 GitHub Release 为准。

- 自动关闭预设：3、5、10、15、30 秒。
- 自定义：1–3600 秒。
- 常驻：不因计时结束关闭，可手动关闭。
- 淡入淡出动画：可单独开关。
- 从 0.8.2 起，鼠标悬停和窗口焦点不暂停倒计时；普通提示按实际经过时间关闭。只有明确展开的选择菜单临时暂停，作答窗本身仍常驻。
- 保存后应用到当前卡片和后续卡片；下次启动保留设置。

旧设置文件缺少新字段时，保持原有的 15 秒显示时间，动画默认关闭。设置保存在控制器原有的 `state/notifications/settings.local.json` 中，不改 Codex 官方/API 的配置文件。

保持原有通知聚合规则：同一环境的新完成通知替换旧完成卡片，最近完成记录仍可在通知页查阅。常驻是关闭计时器，不改变这一聚合规则；关闭提醒、暂停提醒或退出控制器仍会收起卡片。

本轮不把显示设置等同于完整通知接管。提问窗口、回答回传、原生通知隔离的接入证据及未完成项见 [接入检查点](NOTIFICATION-BRIDGE-NEXT.md)。
